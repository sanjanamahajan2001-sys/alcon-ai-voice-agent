3.1 Post-Service Feedback (Immediate / Day 0)
* Objective: Capture "fresh" sentiment and identify immediate quality issues before they escalate.
* Key Logic:
   * Intent Detection: "Are you facing any issue with the car after the service?"
   * Conditional Branching:
      * If YES → Trigger Escalation Protocol (Senior Service Team notification).
      * If NO → Proceed to CSAT/NPS rating (Scale of 1-10).
   * Engagement Strategy: Offer to "Reconsider" feedback if ratings are 8-9, emphasizing Alcon’s commitment to a "Perfect 10" experience.


________________


3.2 Post-Service Feedback (15th Day Monitoring)
* Objective: Long-term performance monitoring to ensure car reliability and brand trust.
* Key Logic:
   * Validation: Check if car is performing well after two weeks of usage.
   * Availability Handling: If the customer is busy, the agent must offer a specific callback window or a WhatsApp link for text-based status updates.
   * API Trigger: Sync results back to the CRM to close the service ticket with "Verified" status.
________________

35. Configurable Flow Builder Architecture (Platform Approach)
34.1 Problem Statement
Current approach defines fixed workflows for each use case.
However, real-world requirements evolve:
* New call flows (sales, complaints, reminders)
* Changes in business logic
* Region-specific variations
Hardcoding flows leads to:
* High development effort
* Slow iteration
* Increased operational cost
________________


35.2 Proposed Solution: Flow Builder System
Design the system as a modular, configurable workflow platform where:
Reusable Building Blocks + Flow Configuration = Dynamic AI Workflows

________________
35.3 Core Concept: Building Blocks
Each interaction is composed of atomic reusable components:
Block Type
	Description
	Input Block
	Capture user input (voice/text)
	Prompt Block
	Ask predefined question
	Decision Block
	Conditional branching (if/else)
	API Block
	Call backend services
	Response Block
	Generate AI response
	Escalation Block
